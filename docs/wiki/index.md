# Wiki index

Last reviewed: 2026-11-27

The project's knowledge base: research, notes, answers to important questions. Anything
discussed in a chat that matters later belongs here (or in decisions.md / CONTEXT.md).

How to keep it:
- One topic per page: `docs/wiki/<topic>.md`, with a `Last reviewed` line. Add it to the list below.
- Link related pages to each other both ways, and to the decisions and terms they rely on.
- When two pages (or a page and the code) disagree, mark it on both: `> Contradiction: ... (see <link>)`,
  and resolve it or list it in [tech-debt.md](../tech-debt.md).
